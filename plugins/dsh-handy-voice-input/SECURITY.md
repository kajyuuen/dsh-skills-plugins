# Security

Report security issues privately to the repository owner. Do not post recordings, transcripts, or credentials in an issue.
Do not include recordings, transcripts, credentials, local paths, or private DSH logs in a public issue.

The plugin starts the configured Handy executable without a shell, passes one temporary WAV path as an argument, bounds captured output, enforces a transcription timeout, and removes the request directory after settlement.
The configured executable runs with the permissions of the DSH host process.
Install only Handy builds and plugin releases from sources you trust.
